# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

cd projects/14-herb-process-record

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 再写一条温度 200 的清炒，结论仍是未放行。
3. checker 看不到写入按钮。

## 出锅冷却观察簿

写入清炒记录即出锅，出锅后自动进入冷却观察簿（写入成功后自动跳到观察页）。观察分钟由炮制员在观察页设定（默认 30 分钟，可改为 0），未满观察分钟禁止对该行点「完成观察」，满分钟后方可完成并记录完成时刻。

顶栏挂「冷却观察」链，观察区独立成页，页内含观察分钟设置、观察中列表、已完成列表三块。质检员可查看观察簿，但不能点完成、不能改观察分钟（后端按角色 403 拦截）。

### 接口

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | /api/observation | 登录即可 | 观察分钟、观察中、已完成 |
| PUT | /api/observation/minutes | 炮制员 | 设定观察分钟（≥0） |
| POST | /api/observation/{id}/complete | 炮制员 | 满观察分钟方可完成，否则 409 |

### 验收（观察簿）

1. 炮制员写一笔后自动进入观察簿，立刻点「完成观察」应失败（提示未满观察分钟）。
2. 将观察分钟改为 0 并保存，再点「完成观察」应成功，完成时刻进入已完成列表。
3. 质检员登录打开观察簿：可见两个列表与当前观察分钟，但没有分钟输入框和完成按钮；直接调接口也被 403 拒绝。
