# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

## 出锅冷却观察簿

写入炮制记录成功后自动进入冷却观察簿（顶栏「冷却观察」，`#/cooling` 独立页）：

- 观察分钟由炮制员在观察簿落地页设置，对之后出锅的记录生效；观察簿含**观察分钟设置、观察中列表、已完成列表**三块。
- 观察中每行有出锅时刻、剩余冷却倒计时；未满观察分钟时「完成观察」被服务端拒绝（400），满分钟后才可完成并记录完成时刻。
- 炮制员可对观察中的单行改观察分钟（可改为 0），改 0 后立即到期可完成；已完成的行不能再改。
- 质检员（checker）可查看观察簿，但没有完成按钮和分钟输入，接口侧同样 403。

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 再写一条温度 200 的清炒，结论仍是未放行。
3. checker 看不到写入按钮。
4. 写入成功后自动跳到冷却观察簿，新行在观察中列表；立刻点「完成观察」提示未满分钟、失败。
5. 把该行观察分钟改为 0，再点「完成观察」成功，行进入已完成列表并带完成时刻。
6. checker 打开冷却观察簿只能看，无完成按钮、无分钟设置。
